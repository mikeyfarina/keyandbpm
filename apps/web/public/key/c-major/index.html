C major chords, relative minor and Camelot code (8B)

C major has no sharps or flats. Its chords are C, Dm, Em, F, G, Am and B°. The relative minor is A minor and the Camelot code is 8B, so it mixes cleanly with 7B, 9B and 8A.

Common progressions in C major

  • C – G – Am – F (I–V–vi–IV): the most used pop progression of the last forty years.
  • C – Am – F – G (I–vi–IV–V): the 1950s doo-wop turnaround.
  • Dm – G – C (ii–V–I): the jazz cadence.
  • Am – F – C – G (vi–IV–I–V): the same four chords as I–V–vi–IV, started on the minor chord for a darker feel.

Relative and parallel keys

The relative minor, A minor, uses exactly the same notes with a different home chord. The parallel minor, C minor, keeps C as home but changes three notes. More on the difference in relative major and minor keys.

Questions people ask

What chords are in C major?

C (I), Dm (ii), Em (iii), F (IV), G (V), Am (vi) and B° (vii°).

What is the relative minor of C major?

A minor. It uses the same 7 notes, C, D, E, F, G, A, B, but centres on A instead of C.

What is the Camelot code for C major?

8B. In Open Key notation it is 1d.

What keys mix well with C major?

F major (7B), G major (9B) and A minor (8A). They sit next to 8B on the Camelot wheel.

How many sharps or flats does C major have?

No sharps or flats.
